Política de Privacidade – CLD Clipes

Última atualização: 16 de novembro de 2026.

Quais dados usamos

Ao conectar o TikTok, a ferramenta recebe um token de acesso e as informações básicas do perfil (escopo user.info.basic), e a permissão de enviar vídeos para os rascunhos (escopo video.upload).

Como usamos

O token serve apenas para enviar os vídeos do próprio dono do canal para os rascunhos da conta dele. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

Onde fica guardado

O token fica salvo só no computador do dono do canal. Não existe servidor ou banco de dados externo.

Como apagar

Você pode revogar o acesso a qualquer momento no app do TikTok (Configurações e privacidade > Segurança > Apps e serviços) e apagar o arquivo do token no computador.

Privacy Policy – CLD Clipes

Last updated: November 16, 2026.

Data we use

When TikTok is connected, the tool receives an access token and basic profile info (user.info.basic scope), plus permission to upload videos to drafts (video.upload scope).

How we use it

The token is used only to send the channel owner's own videos to their own account drafts. No data is sold, shared with third parties or used for advertising.

Storage

The token is stored only on the channel owner's computer. There is no external server or database.

Deletion

You can revoke access at any time in the TikTok app (Settings and privacy > Security > Apps and services) and delete the token file from the computer.
