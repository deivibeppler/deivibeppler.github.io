Política de Privacidade — Estudio Clipes

Última atualização: 16 de novembro de 2026.

O que o app acessa

Com a sua autorização, o app usa a API do YouTube (YouTube Data API v3) para enviar vídeos e gerenciar os vídeos do seu próprio canal. Ele não lê e-mails, contatos, arquivos nem qualquer outro dado da sua Conta do Google.

Como os dados são guardados

O token de acesso fica salvo apenas no computador de quem usa o app. Nenhum dado é enviado a servidores do desenvolvedor, vendido ou compartilhado com terceiros.

Uso de dados das APIs do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O app também está sujeito aos Termos de Serviço do YouTube e à Política de Privacidade do Google.

Como revogar o acesso

Você pode remover o acesso a qualquer momento em myaccount.google.com/permissions.
